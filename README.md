# نموذج مسلم - تطبيق PWA احترافي

تطبيق ويب تقدمي (PWA) يعتمد على قاعدة بيانات الفتاوى السلفية الموثوقة بالذكاء الاصطناعي، جاهز للنشر الكامل على **Firebase Hosting** كملفات Static بدون الحاجة لأي Backend أو VPS أو Node.js على السيرفر.

---

## 🚀 طريقة رفع المشروع على Firebase Hosting

قم بتنفيذ الأوامر التالية عبر موجه الأوامر (Terminal) في مجلد المشروع:

1. **تثبيت أدوات Firebase CLI** (إن لم تكن مثبتة لديك مسبقاً):
   ```bash
   npm install -g firebase-tools
   ```

2. **تسجيل الدخول إلى حساب جوجل المرتبط بـ Firebase**:
   ```bash
   firebase login
   ```

3. **ربط المشروع بمشروعك على Firebase**:
   ```bash
   firebase use private-d338e
   ```
   *(أو قم بتشغيل `firebase init hosting` واختار المجلد الحالي كـ public وحدد إعادة توجيه كل المسارات إلى `index.html`)*

4. **نشر المشروع مباشرة**:
   ```bash
   firebase deploy
   ```

---

## 📂 مكان وضع الملفات
جميع الملفات جاهزة ومضمنة في هذا المجلد:
- `index.html` (الصفحة الرئيسية والشات)
- `welcome.html` (الصفحة الترحيبية وتثبيت التطبيق)
- `database.html` (قاعدة الفتاوى الشاملة والبحث)
- `fatwa.html` (عرض تفاصيل الفتوى المنفردة)
- `manifest.json` (ملف تعريف تطبيق الـ PWA)
- `service-worker.js` (نظام الكاش والعمل Offline)
- `offline.html` (صفحة انقطاع الإنترنت)
- `firebase.json` (إعدادات استضافة فايربيس)
- `icons/` (مجلد الأيقونات بمقاساتها الكاملة)
